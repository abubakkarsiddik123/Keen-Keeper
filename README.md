# 🌿 KeenKeeper

**KeenKeeper** is a modern friendship relationship management web application designed to help users maintain meaningful and consistent connections with the people who matter most.

With KeenKeeper, users can manage their friends, track interactions, set relationship goals, monitor contact frequency, and gain useful insights through a clean and intuitive dashboard.

---

## ✨ Features

### 👥 Friend Management

* Add and manage friends
* View detailed friend profiles
* Profile pictures and personal information
* Bio, email, status, and custom tags
* Archive or delete friends

### 📞 Interaction Tracking

Keep track of how you stay connected with your friends:

* 📞 Phone calls
* 💬 Text conversations
* 📹 Video calls
* 📅 Interaction dates
* 🕒 Complete interaction timeline

### 🎯 Relationship Goals

* Set relationship goals for individual friends
* Track contact frequency
* Monitor upcoming relationship goals
* View days since the last interaction
* Quickly check in with friends

### 📊 Friendship Analytics

Understand your communication habits with visual analytics:

* Call history
* Text history
* Video call history
* Interaction statistics
* Pie chart visualization
* Overall interaction breakdown

### 📋 Timeline

The Timeline provides a complete overview of your friendship interactions.

Users can:

* View all interactions in chronological order
* Filter by **Call**
* Filter by **Text**
* Filter by **Video Call**
* View interaction dates and details

### ⚡ Quick Check-In

Quickly record a recent interaction without navigating through multiple pages.

### 😴 Smart Reminders

* Snooze relationship reminders
* Track upcoming contact goals
* Stay consistent with important friendships

### 📱 Responsive Design

KeenKeeper is designed to provide a smooth experience across:

* 💻 Desktop
* 💻 Laptop
* 📱 Tablet
* 📱 Mobile devices

## 📊 Analytics

KeenKeeper transforms interaction data into easy-to-understand visual insights.

### Interaction Breakdown

The analytics section provides statistics for:

| Interaction Type | Description                   |
| ---------------- | ----------------------------- |
| 📞 Calls         | Total phone call interactions |
| 💬 Texts         | Total text conversations      |
| 📹 Video Calls   | Total video call interactions |

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone <your-repository-url>
```

### 2. Navigate to the Project

```bash
cd KeenKeeper
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```
