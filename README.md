# 🌿 KeenKeeper

**KeenKeeper** is a modern friendship relationship management web application that helps users maintain meaningful connections with friends. It allows users to track interactions, monitor relationship goals, and receive insights through an intuitive dashboard and analytics.

---

## 🚀 Features

- 👥 Manage friends and their profiles
- 📋 View detailed friend information
- 📅 Track days since last contact
- 🎯 Set and monitor relationship goals
- 📞 Log phone calls
- 💬 Log text conversations
- 📹 Log video calls
- 🕒 Timeline of all interactions
- 🔍 Filter timeline by interaction type
- 📊 Friendship analytics with Pie Charts
- ⚡ Quick Check-In feature
- 😴 Snooze reminders
- 📦 Archive friends
- 🗑️ Delete friends
- 📱 Fully responsive design

## 📊 Analytics

KeenKeeper provides visual insights into friendship interactions.

- Call History
- Text History
- Video Call History
- Pie Chart Visualization
- Interaction Statistics

---

## 📅 Timeline

The Timeline page allows users to:

- View all interactions
- Filter by Call
- Filter by Text
- Filter by Video
- View interaction dates

---

## 👥 Friend Details

Each friend profile includes:

- Profile Picture
- Name
- Bio
- Email
- Status
- Tags
- Relationship Goal
- Days Since Contact
- Next Due Date
- Quick Check-In
